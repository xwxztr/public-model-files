# 威胁模型与剩余风险

本包降低公网外联、宿主凭据暴露及未经控制的本地修改风险，不提供零风险承诺。公司验收前仅用合成数据评估。

## 假设

1. Windows 宿主、虚拟化内核、磁盘和公司 CA 未被攻击者控制，且按公司标准修补。
2. 工具包和中继代码在导入前由公司审核，导入哈希经过独立渠道核对；普通 Agent 不能修改宿主工具包。
3. 公司确认唯一目标 HTTPS API 的固定 RFC1918 IPv4、端口、TLS 名称和模型；API 后端不使用未经批准的公网模型、远程工具或遥测。
4. 输入仅为获准交给此模型处理的文件副本，输出不会被宿主自动加载或执行。
5. 每个会话单独使用一个专用共享目录，不与其他用户、任务或不可信宿主程序共用。

## 主要控制及局限

| 威胁 | 本包措施 | 仍然存在的风险 |
|---|---|---|
| Agent 或其子进程外联 | Sandbox `Networking=Disable`，不暴露宿主代理/网卡/浏览器 | 虚拟化漏洞、错误启动方式、管理员重新开启网络不在保障内 |
| API 指向公网或发生重定向 | 固定 RFC1918 IPv4，原始 TCP 直连，固定 Host/SNI，证书校验；3xx 拒绝 | 内网地址可能由路由/VPN映射出去；API 自身可转发公网，需公司网络侧确认 |
| 密钥被模型读取 | 宿主隐藏输入，保存在进程内存；不传客户端 Authorization；不映射宿主配置或用户目录 | 宿主调试、内存转储、管理员、被入侵的上游 API 可见密钥；不能声称硬件级密钥隔离 |
| SSRF、任意 API 转发 | 仅 POST 两类推理路径；Responses 默认关闭；单模型；不接受 URL/任意请求头 | 允许的模型请求本身就包含输入数据，不能替代数据分类/DLP |
| 服务端工具外联 | 仅允许 function，Responses 可允许本地 custom 工具；拒绝远程工具、媒体 URL、文件引用和后台会话 | 提供方若无视工具语义或自行联网，须在服务端治理 |
| 提示注入 | 无宿主用户目录/凭据映射，输入只读，工作副本隔离，默认关命令工具 | Agent 仍能读取获准输入、篡改沙箱工作副本、生成恶意输出；文本提示不是权限边界 |
| 文件通道逃逸 | 消息名固定 UUID；只接受普通单硬链接文件；Windows `OPEN_REPARSE_POINT` 拒绝重解析点；新响应排他创建；父目录检查 | 文件通道不是独立审计过的安全产品；攻击者仍可洪泛目录/磁盘、删除/伪造响应及造成拒绝服务 |
| 会话落盘 | Pi 不保存会话，其余状态在一次性沙箱；正常请求完成后清理通道文件 | 崩溃后通道可能残留明文；宿主分页、转储、备份及 SSD 删除不能保证清除，按公司磁盘加密/保留制度处理 |
| 软件供应链 | 固定版本/提交、npm lock/integrity、禁止安装生命周期脚本、离线打包、依赖清单与哈希 | 公开注册表和上游发行物仍有供应链风险；预编译二进制不等于已从源码可复现构建 |
| 漏洞 | 构建时运行 npm audit 并修复已发现依赖告警 | 扫描不覆盖所有程序、嵌入依赖、OS或未知漏洞；无告警不等于无漏洞 |

## 宿主中继的最小暴露面

宿主不启动 HTTP 监听服务，只轮询一个会话的专用目录。收到 JSON 后执行固定的 HTTPS 推理请求；它不执行命令、动态代码、配置脚本或响应内容。配置只在启动时读取，来自宿主且不映射给沙箱。默认 4 MiB 请求、32 MiB 响应、单请求串行、每会话 500 次调用；并非费用或磁盘配额的完整控制。

只能接受 `https://host[:port]` 或末尾 `/v1` 的地址，固定调用 `/v1/chat/completions`，可选 `/v1/responses`。其他前缀、HTTP、IPv6、公共 IPv4、回环或链路本地目标都拒绝。公司有不同 API 前缀或鉴权格式时需要改造并重新审查，不应关闭 TLS 校验或扩大到任意 URL。

HTTPS 证书校验使用 Python SSL 信任链和主机名验证；本包没有实现完整企业 CRL/OCSP 联机吊销校验或硬件证书固定。必要时在公司 API 网关层强制这些策略。中继不继承系统 HTTP 代理设置；公司网络仍应在宿主或网络设备上实施出站默认拒绝，仅放行模型网关 IP/端口。

## 严格环境的上线条件

必须有公司 IT/安全部门对目标 Windows 补丁、Sandbox策略、API数据流、供应链材料和验收结果的批准。若不允许 Sandbox 文件共享，使用公司批准的隔离虚拟机/VDI 加独立模型网关；本包的文件通道方案不适用。不要退化为在宿主安装 Agent 后只设置几个环境变量。

不得将完整宿主盘、用户目录、SSH、浏览器、云凭据、Docker socket、远程桌面或未经审查的执行入口共享给 Agent。中继只能处理当前用户单个会话，不能作为多租户服务部署。
