## 准入与来源

- [ ] 核对完整 ZIP 哈希、内部批准记录、来源清单、上游许可证及运行时版本。
- [ ] 使用公司病毒/EDR和漏洞扫描工具扫描离线包和解压文件；保存报告。本次交付没有已通过的恶意软件扫描报告。
- [ ] 运行 `windows\Verify-Payload.ps1`，确认所有 payload 文件均与清单相同、无额外文件或重解析点。
- [ ] 确认 Windows 补丁/支持状态、虚拟化及 Sandbox 功能获得公司许可。
- [ ] 确认 API 服务器及其反代**不会**把提示词、代码、工具结果、遥测或日志发向公网；确认访问、留存、删除和模型训练政策。

## 网络与密钥边界

- [ ] 检查生成的 `Agent.wsb`：Networking、剪贴板、音视频、打印机和vGPU都为Disable，且共享目录只有本包规定的五处。
- [ ] 在沙箱内运行 `Get-NetAdapter` / `Get-NetRoute`，记录可用接口与路由，确认没有通往宿主、公司网或公网的网卡/路由；回环不作为外联网卡。
- [ ] 在沙箱内用 PowerShell、随包 Python、Node 和 Agent 的子进程分别尝试连接公司提供的**合成测试目标IP**（内网和外网），全部直接 TCP 连接应失败。不要只验证 Agent 主程序。
- [ ] 开始、首次任务、空闲、切换模型、报错、关闭、分享/反馈/更新尝试期间，在宿主和公司边界抓取 DNS/IPv4/IPv6/HTTP/HTTPS 连接。Agent 沙箱不能出现外部连接；宿主中继只能连批准的私网 IP:端口。
- [ ] 修改配置为公共IPv4、169.254.169.254、127.0.0.1、IPv6、HTTP、带query/用户信息的URL，确认中继拒绝启动。恢复获批配置。
- [ ] 用测试HTTPS服务返回302/307到第二个测试地址，确认中继不跟随且没有第二次连接。
- [ ] 测试自签名/不受信/主机名不符/过期证书均失败；符合公司CA和SAN的证书成功。严格吊销校验需求在公司网关层另行验收。
- [ ] 确认沙箱中看不到宿主API密钥、真实配置、公司CA文件、浏览器/SSH/云凭据和其他宿主用户目录。
- [ ] API端记录实际连接源、Host/SNI、模型ID和路径，验证无未知目的地与提供商回退。代理环境变量不得改变固定IP连接目的地。

## 功能与协议

- [ ] Pi 和 OpenCode 用公司测试模型完成一轮文本回复、一次获准的文件读取、一次编辑，检查真正执行了function tools而不是模型声称成功。
- [ ] DeepSeek Harness 在沙箱内部浏览器打开本地令牌URL；确认只显示corp模型；完成一次真实测试任务并检查工具权限、UI和会话行为。
- [ ] 验证网页搜索、MCP、扩展安装、更新、分享和反馈无法访问公网；不能为了消除报错而临时开网。
- [ ] API收到的请求带正确模型、`store=false`；尝试错误模型、未知接口、远程MCP/Web工具、媒体URL/文件引用，必须拒绝。
- [ ] 断开或停止宿主中继，Agent应报错/超时，不应回退到其他模型。超大请求/响应、超时、请求预算耗尽应失败关闭。
- [ ] Codex仅在公司支持Responses API时启用，验证SSE、函数工具、用量、错误、取消和上下文收缩；仅Chat网关必须保持禁用。若发现compact等未允许接口需求，应先审查适配，不能把中继扩大成任意反代。

## 文件与恢复

- [ ] 沙箱无法写入只读工具包/输入；宿主原始项目内容未改变。
- [ ] 关闭沙箱后工作副本消失，选定输出保留在独立输出目录；输出在宿主使用前经过代码/脚本/宏与恶意软件检查。
- [ ] 用无敏感数据测试链接/junction/硬链接消息、畸形JSON、重复键、重复响应文件和磁盘洪泛；不得读写宿主任意文件。磁盘配额和清理需公司管理。
- [ ] 模拟超时/崩溃，检查exchange残留、会话日志和磁盘加密/备份策略；确认不会上传GitHub或公网反馈。
- [ ] 确认实际完成公司真实任务所需的编译器、Git、SDK等均经过独立离线审查；本包默认限制命令工具，不包含完整开发环境。
