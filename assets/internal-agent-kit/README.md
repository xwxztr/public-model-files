# Windows 内网 Agent 加固候选包

**结论：这四个项目都不能因为“开源”或“支持本地 API”就被认定默认零公网通信、零信息安全风险。** 本包使用固定版本、离线依赖、保守配置和禁网 Windows Sandbox，让 Agent 只能通过受限文件中继调用公司 API。它是需要公司验收的候选包，不是安全认证或“零风险版本”。

你需要的日常流程是：导入一次离线包 → 本地填写公司 API 配置 → 启动中继 → 打开禁网 Sandbox → 使用 Agent → 人工导出并审查结果。公司内部不运行 npm、pip、在线安装器，也不登录公网账户。

| 工具 | 随包版本 | Chat Completions | 本包默认用途 |
|---|---|---|---|
| Pi | 1.5.2 | 支持 | 首选，阅读、编辑、写入文件，关闭 bash 与扩展 |
| OpenCode CLI | 1.19.5，Windows x64 baseline | 支持 | 文件工作，修改询问、命令/网页工具拒绝 |
| DeepSeek Harness CLI/Web | 0.2.2-rc.3 | 支持自定义提供商 | 较复杂的 Web 工作台，关闭遥测和高权限工具；预发布软件 |
| Codex CLI | 0.169.0 | **不支持该协议** | 随包供评估；仅公司明确支持 Responses API 时可启用 |

“OpenAI 兼容”必须落实到具体路径和工具调用协议；只有 `/v1/chat/completions` 时不要选择 Codex。模型本身仍运行在公司服务上，这不是不需要模型服务的独立推理软件。

下载本仓库 Releases 中的 `Internal-Agent-Windows-x64-*.zip`、`SHA256SUMS.txt` 和手册。源码在 `assets/internal-agent-kit/`，不会覆盖仓库原有文件。Release 的 `Source code (zip)` 不包含预装运行时，不能替代完整离线包。

先读 [安装和使用手册](docs/INSTALL.zh-CN.md)，安全部门读 [源码核查报告](docs/AUDIT.zh-CN.md)、[威胁模型](SECURITY.md) 和 [验收清单](docs/ACCEPTANCE.zh-CN.md)。实际测试结果在 [验证记录](docs/VALIDATION.zh-CN.md)。

## 防护结构

```text
Windows 宿主机（公司网络策略继续生效）
  宿主中继：真实密钥 + 固定内网 IPv4 + HTTPS 证书校验
       ↑ 请求/响应文件，仅允许指定模型、指定 API 路径
  ┌────┴──────────────────────────────┐
  │ Windows Sandbox：Networking=Disable               │
  │ Agent → 127.0.0.1:8765 → 文件桥                    │
  │ Agent、插件、PowerShell 等子进程均没有外部网络接口 │
  │ 工具包和输入目录只读；工作副本位于沙箱内部         │
  └───────────────────────────────────┘
       ↓ 人工选择导出
  独立输出目录（内容仍须审查，禁止自动执行）
```

网络隔离约束的是整个沙箱，而不是只约束某一个 exe。中继不接受目的 URL，不使用 DNS 或代理，不跟随重定向，真实 API 密钥不进入沙箱。模型响应仍可能包含错误、恶意指令或不安全代码；宿主机和公司模型服务也必须可信。

## 使用边界

- 目标是 Windows 10/11 **x64**、支持 Sandbox 的专业/企业/教育等版本，且启用虚拟化。Home 和 ARM64 不属于本包支持范围。
- 本机验证环境没有安装 Windows Sandbox 功能，因此未完成虚拟机隔离实测；必须完成公司现场验收后再处理真实资料。
- 完整离线包包含上游程序，未声称删除了上游所有联网代码。即使配置被 Agent 改动，网络边界仍依赖 Sandbox；不要在宿主机直接运行其中的 Agent。
- 为降低权限，默认关闭命令执行、第三方扩展、MCP、联网搜索、分享和自动更新，部分成熟 Agent 功能因而受限。
- 仅支持纯文本模型输入。中继缓冲整次 SSE 响应后返回，因此界面可能等待一段时间才显示，默认单次上限 180 秒。
- 公司 API 如果再转发公网模型，或服务端记录/外传请求，客户端隔离不能解决。`store=false` 也不能代替服务端数据管理制度。

本仓库和 GitHub Releases 只存放公开项目、通用加固代码、占位符配置和测试记录。**不要提交公司代码、真实地址、模型内部名称、CA、密钥、会话或日志。**
